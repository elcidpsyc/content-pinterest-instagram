# Canva Design Skill

Gera especificações detalhadas e prontas para implementar no Canva, com foco em design minimalista para Pinterest e Instagram — especialmente conteúdo de psicologia profunda, cura e autoconhecimento.

## Conhecimento Base do Canva

### Dimensões por Plataforma
| Formato | Dimensão | Proporção |
|---|---|---|
| Pinterest Pin | 1000 × 1500 px | 2:3 |
| Pinterest Pin longo | 1000 × 2100 px | 1:2.1 |
| Instagram Post | 1080 × 1080 px | 1:1 |
| Instagram Portrait | 1080 × 1350 px | 4:5 |
| Instagram Story / Reel | 1080 × 1920 px | 9:16 |
| Instagram Carousel slide | 1080 × 1080 px | 1:1 |

### Fontes Disponíveis no Canva (Gratuitas)
**Serif elegantes (títulos emocionais):**
- Cormorant Garamond — elegante, literário, introspectivo
- Playfair Display — sofisticado, alto contraste
- Libre Baskerville — clássico, legível
- EB Garamond — leveza e profundidade

**Sans-serif limpas (corpo e subtexto):**
- DM Sans — moderno, neutro, muito legível
- Lato — humanista, warm
- Montserrat — geométrico, contemporâneo
- Inter — digital-first, altamente legível
- Raleway — elegante, leveza

**Combinações recomendadas:**
- Título: Cormorant Garamond Bold / Corpo: DM Sans Regular
- Título: Playfair Display / Corpo: Lato Light
- Título: EB Garamond Italic / Corpo: Inter Regular

### Paletas de Cor para Psicologia Profunda

**Paleta Serenidade (padrão recomendado):**
- Fundo: `#F5EFE6` (bege quente)
- Texto principal: `#2C2420` (marrom escuro quase preto)
- Acento: `#C4A882` (dourado opaco)
- Secundário: `#8BA8A0` (sage green)
- Neutro: `#FAFAF8` (branco gelo)

**Paleta Profundidade:**
- Fundo: `#1C1C1E` (quase preto)
- Texto: `#F0EDE8` (off-white)
- Acento: `#9B7B5B` (terracota suave)
- Destaque: `#C8B9A2` (areia)

**Paleta Névoa:**
- Fundo: `#ECEDEF` (cinza névoa)
- Texto: `#2C2C2C` (grafite)
- Acento: `#A8B5C8` (azul-cinza)
- Secundário: `#D4C5B5` (rosé neutro)

**Paleta Terra:**
- Fundo: `#F0E0D6` (terracota muito suave)
- Texto: `#2C1810` (marrom profundo)
- Acento: `#A05030` (terracota médio)
- Secundário: `#E8D5C4` (pêssego claro)

### Elementos Canva para Estilo Minimalista
- **Linhas**: Usar elementos de linha simples (1–2pt), cor do texto principal
- **Formas**: Círculos e retângulos sem preenchimento (apenas stroke)
- **Ícones**: Buscar "line" ou "outline" na aba Elementos — estilo traço fino
- **Ilustrações**: Buscar "minimal line" ou "simple illustration" nos elementos
- **Evitar**: gradientes pesados, sombras fortes, texturas complexas, clipart colorido

## Workflow

Crie uma lista de tarefas e trabalhe uma por vez.

### 1. Receber o Briefing

Obtenha do contexto ou pergunte:
- Plataforma e formato (Pinterest Pin, carrossel Instagram, etc.)
- Tema / copy já definido (título, subtexto, citação)
- Paleta preferida ou deixar a skill escolher
- Nível de detalhe: instrução rápida ou passo a passo completo

### 2. Definir Estrutura Visual

Escolha o layout com base no conteúdo:

**Layout A — Texto Central (minimalista puro)**
```
[espaço negativo — 20% do height]
[Título grande — serif, 2–3 linhas]
[espaço]
[subtexto — sans-serif, 1–2 linhas]
[espaço negativo — 20% do height]
[rodapé discreto — logo/perfil]
```

**Layout B — Imagem + Texto (metade/metade)**
```
[ilustração linha art — 50% superior]
[linha divisória fina — 1pt]
[Título — serif bold]
[subtexto]
[CTA ou citação em itálico]
```

**Layout C — Citação Destacada**
```
[aspas decorativas grandes — opacity 20%]
[Citação principal — serif italic, grande]
[linha divisória]
[atribuição — "— Autor" — sans-serif small]
[espaço]
[subtexto contextual]
```

**Layout D — Carrossel Educacional**
```
Slide 1 (Capa): título impactante + elemento visual central
Slides 2–5: uma ideia por slide, ícone + texto curto
Slide final: CTA + pergunta reflexiva
```

### 3. Gerar Especificação Completa Canva

Produza instruções no seguinte formato:

```
═══════════════════════════════════════
ESPECIFICAÇÃO CANVA — [Nome do Pin/Post]
═══════════════════════════════════════

DIMENSÃO: [ex. 1000 × 1500 px — Pinterest Pin]
LAYOUT: [A / B / C / D]

── FUNDO ──────────────────────────────
Cor: #F5EFE6
Tipo: cor sólida (sem gradiente)

── ELEMENTO VISUAL ────────────────────
Tipo: [ilustração / ícone / linha / nenhum]
Busca no Canva: "[termo de busca]"
Posição: [topo / centro / fundo] — [% do canvas]
Tamanho: [largura × altura em px ou %]
Cor: #[código] (recolorir pelo Canva se necessário)
Opacidade: [100% / 80% / 60%]

── TEXTO PRINCIPAL ────────────────────
Fonte: [nome da fonte]
Estilo: [Bold / Regular / Italic]
Tamanho: [pt]
Cor: #[código]
Alinhamento: [Centro / Esquerda]
Posição: Y [%] do canvas
Largura máxima: [%] da largura total
Conteúdo: "[texto exato]"

── SUBTEXTO ───────────────────────────
Fonte: [nome]
Estilo: [Regular / Light]
Tamanho: [pt]
Cor: #[código]
Espaçamento entre linhas: [1.4 / 1.6]
Conteúdo: "[texto exato]"

── ELEMENTOS ADICIONAIS ───────────────
[linhas, separadores, ícones, assinatura]

── EXPORTAÇÃO ─────────────────────────
Formato: PNG
Qualidade: Alta (300 DPI se disponível)
Nome do arquivo: [nome-descritivo.png]

══ DICA CANVA ═════════════════════════
[dica específica para facilitar a criação]
═══════════════════════════════════════
```

### 4. Passo a Passo de Criação no Canva

Gere instruções numeradas:

```
PASSO A PASSO — CANVA

1. Acesse canva.com → Criar design → Tamanho personalizado
   → Digite: [largura] × [altura] px → Criar

2. Clique no fundo → cor → cole o código: #[código]

3. [Adicionar elemento visual]
   Aba "Elementos" → busque "[termo]"
   → Selecione o estilo de linha fina
   → Posicione em [posição]
   → Ajuste a cor para #[código]

4. [Adicionar texto principal]
   Aba "Texto" → "Adicionar título"
   → Fonte: [nome] → Tamanho: [pt]
   → Cor: #[código]
   → Digite: "[texto]"
   → Centralize horizontalmente

5. [Adicionar subtexto]
   → Nova caixa de texto → Fonte: [nome] Light
   → Tamanho: [pt] → Espaçamento: 1.5
   → Digite: "[texto]"

6. [Elementos finais: linha, assinatura, etc.]

7. Exportar: Compartilhar → Baixar → PNG → Alta qualidade
```

### 5. Variações e Alternativas

Ofereça:
- Versão escura da mesma peça (inverter paleta)
- Variação de fonte (mais bold vs. mais delicada)
- Versão com e sem elemento visual

### 6. Checklist Final

Antes de entregar, verifique:
- [ ] Hierarquia visual clara (o olho sabe onde ir primeiro)
- [ ] Mínimo 40pt de margem em todos os lados
- [ ] Máx. 2 fontes diferentes por peça
- [ ] Máx. 3 cores por peça
- [ ] Texto legível em thumbnail pequeno (pré-visualize a 25%)
- [ ] Espaço negativo respeitado (não lotado)
- [ ] Proporção correta para a plataforma

## Tom Visual

- Minimalista — menos é mais
- Elegante sem ser frio
- Espaço negativo como elemento de design
- Tipografia como protagonista
- Cor como acento, não como decoração

## Wrap Up

Após gerar as especificações, confirme:
- Formato e dimensão usados
- Paleta aplicada
- Layout escolhido e justificativa
- Sugira próximos passos (teste A/B, versão Story, adaptação para Instagram)
