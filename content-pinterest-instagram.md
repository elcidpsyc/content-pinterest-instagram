# Content Pinterest & Instagram Skill

Generate optimized content for Pinterest and Instagram, including captions, hashtags, pin descriptions, and content strategies.

## Workflow

Make a todo list for all the tasks in this workflow and work on them one after another.

### 1. Understand the Goal

Ask the user (or infer from context) what they need:
- **Type**: Pin, Instagram post, Reel, Story, Carousel, or content calendar
- **Niche/Topic**: Product, lifestyle, educational, inspirational, etc.
- **Tone**: Professional, casual, playful, inspirational
- **Target audience**: Demographics, interests
- **Any existing brand guidelines or examples**

### 2. Generate Pinterest Content

For Pinterest pins, produce:

```
Title (max 100 chars): <compelling, keyword-rich title>

Description (max 500 chars):
<engaging description with primary keyword in first sentence,
natural keyword usage, clear value proposition, call-to-action>

Hashtags (5–10):
#Keyword1 #Keyword2 #Keyword3 ...

Board suggestion: <relevant board name>

Image/visual notes: <recommended aspect ratio 2:3 or 1:1, color palette tips, text overlay suggestions>
```

**Pinterest SEO tips to apply:**
- Use long-tail keywords naturally
- Include the main keyword in both title and description
- Write for humans first, search engines second
- Add a soft CTA (e.g., "Save for later", "Click to learn more")

### 3. Generate Instagram Content

For Instagram posts, produce:

```
Caption:
<Hook line — grab attention in first 1-2 lines>

<Body — 2-4 short paragraphs with value, story, or tips>

<CTA — ask a question, invite to comment, or direct to bio link>

Hashtags (20–30):
<mix of high-volume (1M+), medium (100K–1M), and niche (<100K) hashtags>

Alt text suggestion: <descriptive alt text for accessibility and SEO>

Best posting time: <based on niche, suggest a general time window>
```

**Instagram engagement tips to apply:**
- Start with a strong hook that stops the scroll
- Use line breaks for readability
- Place hashtags at the end or in first comment
- Include one clear CTA per post
- Use relevant emojis sparingly to add personality

### 4. Generate Content for Reels / Stories (if requested)

For Reels:
```
Hook (0–3s): <text or spoken line to stop scrolling>
Script outline:
  - Point 1
  - Point 2
  - Point 3
CTA: <subscribe, follow, comment, save>
Audio suggestion: <trending sound or voiceover style>
```

For Stories:
```
Slide 1 — Hook: <question or bold statement>
Slide 2–4 — Value: <short tips or steps>
Last slide — CTA: <poll, link, DM>
```

### 5. Generate Hashtag Sets

Create three tiers of hashtag sets for a given topic:

| Tier | Volume | Count |
|------|--------|-------|
| High | > 1M posts | 5 |
| Medium | 100K–1M | 10 |
| Niche | < 100K | 10–15 |

Always mix all three tiers for maximum reach.

### 6. Content Calendar (if requested)

Produce a weekly or monthly content plan:

```
Week 1:
  Mon — [Post type] Topic: ...
  Wed — [Post type] Topic: ...
  Fri — [Post type] Topic: ...
  Sun — [Story/Reel] Topic: ...
```

Align with:
- Seasonal events and holidays
- Product launches or campaigns
- Consistent brand themes

## Output Format

Always present content in clearly labeled, copy-paste-ready blocks. Offer variations when useful (e.g., two caption options, A/B hook test).

## Wrap Up

After generating content, summarize:
- What was created (type and quantity)
- Key SEO/engagement strategy applied
- Suggested next steps (scheduling, A/B testing, repurposing)
